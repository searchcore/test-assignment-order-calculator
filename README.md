# Расчёт заказа товаров

Консольная программа, которая рассчитывает, сколько единиц каждого товара нужно заказать у поставщика.

## Как считается заказ

Запас планируется на весь срок поставки и ещё на 7 дней. Товары, уже находящиеся в пути, считаются поступившими не позже новой партии.

| Величина | Формула |
|---|---|
| Период покрытия | `lead_days + 7` |
| Целевой запас | `ceil(daily_sales × период покрытия + safety_stock)` |
| Доступное количество | `stock + incoming` |
| Заказ | `max(0, целевой запас − доступное количество)` |

Количество для заказа всегда целое. Целевой запас округляется вверх.

## Формат входного файла

CSV-файл со следующими столбцами:

| Поле | Описание |
|---|---|
| `sku` | Код товара (уникальный) |
| `name` | Название товара |
| `stock` | Остаток на складе, шт. |
| `daily_sales` | Средние продажи за день, шт. (может быть дробным) |
| `incoming` | Товар в пути от поставщика, шт. |
| `lead_days` | Срок следующей поставки, дней |
| `safety_stock` | Страховой запас, шт. |

Значения `stock`, `incoming`, `lead_days` и `safety_stock` должны быть неотрицательными целыми числами, `daily_sales` неотрицательным числом.

Пример:

```csv
sku,name,stock,daily_sales,incoming,lead_days,safety_stock
A001,Coffee,12,4,0,5,8
A002,Tea,50,3,20,4,10
```

## Установка

Требуется Python 3.12 или новее.

Скачайте проект в любую удобную директорию.

## Запуск (Windows)

У программы нет графического интерфейса, работа выполняется через командную строку.

1. Откройте командную строку.
2. Перейдите в папку проекта:

   ```bat
   cd /d Путь\до\папки\с\проектом
   ```

### Варианты использования

Показать доступные параметры:

```bat
py -m src.presentation.cli --help
```

Рассчитать заказы и вывести результат в консоль:

```bat
py -m src.presentation.cli --products ./путь/до/файла.csv --print-result
```

Рассчитать заказы и сохранить результат в CSV-файл:

```bat
py -m src.presentation.cli --products ./путь/до/файла.csv --output-file ./путь/до/результата.csv
```

### Пример результата

Пример результата на тестовых данных в виде .csv:

```csv
sku,to_order,description
A001,44,"Целевой запас: 56, на складе: 12, продажи в день: 4"

```
